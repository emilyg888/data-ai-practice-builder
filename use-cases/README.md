## How to use
1. Copy `template-use-case.md` for each post.
2. Name files as `YYYY-MM-DD-short-title.md`.
3. Fill source fields from the post URL and text.
4. Keep each use case focused on one business scenario.

## Suggested quality checks
- Problem statement is specific and measurable.
- Actors and decisions are explicit.
- Input and output data are concrete.
- Risks and controls are realistic.
- KPIs can be tracked over time.
