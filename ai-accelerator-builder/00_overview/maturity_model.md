# Delivery Maturity Model

| Level | Name | Description |
|---|---|---|
| 0 | Not Present | Capability does not exist |
| 1 | Ad Hoc | Informal, fragmented, inconsistent |
| 2 | Repeatable | Some repeatable practices exist |
| 3 | Governed | Ownership, standards and controls exist |
| 4 | Industrialised | Automated, reusable, monitored |
| 5 | Adaptive | Continuously optimised and self-improving |

## AI-era question
Can AI safely consume, explain, reason over, or act on this capability?
