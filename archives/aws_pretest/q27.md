Question
A company is building a data retrieval and workflow system. The company uses an FM in Amazon Bedrock through an API call to build the system. The company wants to use AWS Step Functions in a structured way to make the FM break down each problem into a series of logical reasoning steps.

Which solution will implement this reasoning pattern in the MOST consistent way?

Correct answer: A

A
Create a state machine with ReAct pattern states. Configure each state to invoke the FM with specific prompts for observation, reasoning, and action planning. Use the built-in Step Functions error handling and retry logic for model invocations.

Correct. You can use Step Functions to define state machines that implement complex logic through a series of steps and branches. The ReAct pattern provides a structured way for an FM to systematically break down and reason through each step of a complex problem. Using built-in Step Functions error handling ensures reliability in model invocation.

B
Create a state machine that implements chain-of-thought reasoning with explicit prompt templates for each step. Use Choice states to dynamically adjust the reasoning path based on intermediate responses.

Incorrect. This solution implements sequential reasoning steps. However, using Choice states to dynamically adjust the reasoning path can cause inconsistent problem-solving approaches across different scenarios. Dynamic branching is not suitable to maintain a predictable, structured decomposition of complex problems. This solution does not provide a consistent framework to break down problems into logical steps that you can apply across multiple domains.

Learn more about Choice states in Step Functions.

C
Create a state machine that attempts to parallelize all reasoning steps simultaneously. Configure concurrent FM invocations to process different aspects of the problem and aggregate results in a final state.

Incorrect. Attempting to parallelize all reasoning steps simultaneously cannot provide structured, sequential reasoning. Complex problem-solving often requires each step to build upon the insights and conclusions from previous steps. Step Functions supports parallel execution. However, using Step Functions for all reasoning steps would break the logical flow that you need for effective problem-solving.

Learn more about Step Functions parallel workflows.

D
Create a state machine that uses the ReAct pattern by passing all previous reasoning steps as context in each FM invocation. Store the complete conversation history in the Step Functions execution state and include the entire history with each new prompt.

Incorrect. Passing the complete conversation history with each model invocation is inefficient and could exceed model context limits. This solution does not properly separate the reasoning steps into distinct states. This solution could lead to performance issues as the conversation history grows.
