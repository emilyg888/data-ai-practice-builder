Question
A financial services company needs to access Amazon Bedrock from an application that runs in a private subnet. For security and compliance reasons, the application must make Amazon Bedrock API calls without traversing the public internet. The solution needs to enable logging through VPC Flow Logs and AWS CloudTrail. The solution must operate without internet gateway access.

Which solution will meet these requirements?

Correct answer: B

A
Configure an Application Load Balancer (ALB) in a public subnet to proxy Amazon Bedrock API requests from the private subnet to the Amazon Bedrock public endpoints.

Incorrect. ALBs can proxy requests. However, placing an ALB in a public subnet sends Amazon Bedrock calls to public endpoints over the internet. Therefore, this solution does not meet the requirement to avoid traversing the public internet.

Learn more about ALBs.

B
Create a VPC interface endpoint for the Amazon Bedrock Runtime service. Configure the private subnet route tables to direct Amazon Bedrock API traffic through the endpoint.

Correct. You can create a VPC endpoint for the Runtime service to provide secure, private access to Amazon Bedrock directly through the AWS network. This solution provides API calls without internet access. This solution maintains security through private networking. This solution supports logging through VPC Flow Logs and CloudTrail.

Learn more about Amazon Bedrock VPC interface endpoints.

Learn more about interface VPC endpoints.

C
Deploy a NAT gateway in a public subnet. Configure the private subnet route tables to direct Amazon Bedrock API traffic through the NAT gateway.

Incorrect. A NAT gateway is a managed AWS service that allows instances in private subnets to access the internet while preventing inbound connections from the internet. A NAT gateway would allow private subnet resources to access Amazon Bedrock. However, this solution requires internet gateway access and routes traffic over the public internet. Therefore, this solution does not meet the requirement to avoid traversing the public internet.

Learn more about NAT gateway.

D
Create a VPC gateway endpoint for the Amazon Bedrock Runtime service. Configure the private subnet route tables to direct Amazon Bedrock API traffic through the endpoint.

Incorrect. A VPC gateway endpoint is a gateway that you specify as a target for a route in your route table. The traffic must be destined to either Amazon S3 or Amazon DynamoDB. Runtime service does not support VPC gateway endpoints. VPC gateway endpoints are only available for Amazon S3 and DynamoDB.

Learn more about gateway endpoints.
