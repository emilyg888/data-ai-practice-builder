Question
An investment company wants to use Amazon Bedrock to summarize complex financial documents. The solution must catalog and manage prompts from the summarization process. The prompts need to be templated with variables for client company names and document content. The solution must provide prompt versioning, a comparison of different versions, and prompt testing before deployment.

Which solution will meet these requirements with the LEAST operational overhead?

Correct answer: D

A
Store prompts in Amazon S3 as JSON templates. Use Amazon Bedrock Prompt Management for A/B testing of different prompt versions. Create a custom AWS Lambda function to handle prompt versioning and parameter substitution. Use Amazon CloudWatch to track prompt performance metrics.

Incorrect. Amazon S3 is an object storage service that offers versioning capabilities to track changes of the objects over time. Amazon S3 can store JSON templates. However, Amazon S3 does not provide built-in prompt cataloging, versioning, or testing. Using Amazon S3 requires additional Lambda logic to implement parameter substitution and version control. Therefore, this solution requires additional operational overhead. You can use CloudWatch for monitoring. However, this solution duplicates built-in capabilities that Prompt Management already provides.

B
Use Amazon Bedrock Prompt Management to create separate prompts for each financial document type. Implement a naming convention to track prompt versions. Use the compare versions feature to test different prompt versions and to select the highest-performing version for each document type. Create static system prompts that define the model's role as a financial analyst. Use the prompt testing feature to validate prompts before deployment.

Incorrect. Prompt Management supports prompt cataloging, version comparison, and prompt testing. You can manage versioning by creating separate prompts for each document type by using naming conventions. However, this method alone is error-prone and not scalable. This solution does not provide the formal prompt versioning and parameterized templating that the company requires. Static system prompts do not provide customization of the model's role for different client company contexts. This solution uses Prompt Management features to test and compare versions. However, this solution does not meet the requirements for parameterized variables to handle client company names and document content dynamically. This solution requires additional manual effort to maintain and update prompts for each new document type.

Learn more about Prompt Management.

C

Use prompt templates with parameterized variables for client company names and document content. Test each version by deploying the version to a staging environment through Amazon Bedrock APIs. Select the appropriate option for production after testing.

Incorrect. Prompt Management provides a centralized way to store, catalog, and manage prompts. Prompt Management supports parameterized templates with variables and system instructions to control the model's role and tone. However, this solution requires manual deployment to a staging environment for testing. This solution requires additional operational overhead to deploy the versions.

Create prompts in Amazon Bedrock Prompt Management. Define system instructions that establish the model's role as a financial analyst. Include parameterized variables in the user message template. Use the compare versions feature to test different prompt versions without deployment. Create a prompt version with the selected prompt to run by using Amazon Bedrock APIs.

Correct. Prompt Management provides a centralized service to store, catalog, and manage prompts. Prompt Management supports parameterized templates with variables and system instructions to control the model's role and tone. This solution offers built-in capabilities for prompt versioning, testing, and deployment without requiring custom infrastructure. The compare versions feature provides prompt testing and side-by-side evaluation without deployment. Prompt versioning ensures that you can lock and execute the selected prompts through Amazon Bedrock APIs.
