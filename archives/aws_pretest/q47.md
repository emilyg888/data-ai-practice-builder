Question
A retail company wants to reduce delays and manual effort in inventory replenishment. The company wants employees to be able to check inventory levels and submit inventory requests in natural language. The solution must automatically invoke internal supply chain processes with minimal ongoing maintenance. The solution must provide built-in Model Context Protocol (MCP) support. The company stores all inventory and data in Amazon Aurora.

Which solution will meet these requirements with the LEAST operational overhead?

Correct answer: B

A
Build an AI-powered chat assistant by using Amazon Lex. Create an AWS Lambda function that parses inventory requests and pushes request details to an Amazon SQS queue. Use the queue for backend supply chain microservices that run on Amazon ECS on AWS Fargate.

Incorrect. Amazon Lex is a conversational AI service that you can use for conversational AI assistants. Amazon Lex provides natural language processing. Lambda, Amazon SQS, and ECS on Fargate can coordinate backend processing. However, this solution does not provide the built-in MCP support that you need. This solution introduces multiple components to manage, including Lambda, Amazon SQS, and Amazon ECS. Therefore, this solution requires additional operational overhead.

B
Deploy an agent by using Amazon Bedrock AgentCore Runtime with Strands Agents. Configure a prebuilt MCP server to expose Aurora inventory and store data as MCP tools. Integrate the agent with a company chat assistant interface.

Correct. You can use AgentCore Runtime with Strands Agents to build AI agents with built-in MCP support. A prebuilt MCP server can directly expose Aurora inventory and store data as MCP tools. This solution eliminates the need for custom containers or API management. This solution provides natural language access to data. This solution automates supply chain actions with the least operational overhead because Amazon Bedrock handles orchestration and hosting.

Learn more about AgentCore Runtime.

C
Create a REST API by using Amazon API Gateway in front of an AWS Lambda function. Configure the Lambda function to query Aurora for inventory information and invoke an AWS Step Functions workflow to handle replenishment tasks.

Incorrect. API Gateway and Lambda provide a pattern to build REST APIs. Step Functions can orchestrate workflows. However, this solution requires additional operational overhead to build and maintain the architecture. Additionally, this solution does not use MCP and requires manual API definitions and workflow coordination.

Learn more about Lambda.

Learn more about API Gateway.

D
Develop and host a custom MCP server on Amazon ECS on AWS Fargate. Implement MCP tools to connect to Aurora and invoke supply chain APIs. Integrate the server with an Amazon Bedrock agent.

Incorrect. A custom MCP server deployed on Amazon ECS can connect to Aurora and expose supply chain APIs as MCP tools. For this solution, you must build, deploy, and scale your own containerized MCP implementation. Therefore, this solution requires additional operational overhead compared to using prebuilt MCP support in AgentCore.
