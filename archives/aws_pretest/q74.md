Question
A software company is launching an AI assistant by using Amazon Bedrock. The AI assistant will help users troubleshoot issues by quickly exploring logs and documentation, and then recommending actions for remediation.

A GenAI developer wants to set up Amazon Bedrock Guardrails. The GenAI developer wants to add protection against SQL injection. The GenAI developer wants to add a post-generation factuality check to prevent recommendations based on inaccurate information.

Which combination of actions will meet these requirements? (Select TWO.)

Correct answer: A + C

A
Add a prompt attack filter.

Correct. Guardrails provide safeguards for GenAI applications. You can configure guardrails to protect against prompt attacks, including jailbreaks and prompt injection.

Learn more about prompt attack filters in Guardrails.

B
Add a misconduct content filter.

Incorrect. Guardrails provide safeguards for GenAI applications. Misconduct content filters in guardrails prevent the GenAI application from engaging in criminal activity or providing information that could be potentially harmful. This filter does not protect against SQL injection.

Learn more about content filters in Guardrails.

Learn more about prompt attack filters in Guardrails.

C
Add a contextual grounding check.

Correct. Guardrails support contextual grounding checks to detect and filter hallucinations in model responses.

Learn more about grounding checks in Guardrails.

D
Use an LLM-as-a-judge job to check for factuality.

Incorrect. Amazon Bedrock evaluations support LLM-as-a-judge jobs. These jobs use an LLM to score the responses from another model. You can use LLM-as-a-judge jobs to check for factuality. However, LLM-as-a-judge jobs run as batch jobs or offline assessments to compare model performance. These evaluations do not integrate into runtime guardrails for live post-generation checks. Therefore, this approach does not meet the requirement to enforce factuality during customer interactions.

Learn more about Amazon Bedrock evaluations and LLM-as-a-judge.

Learn more about grounding checks in Guardrails.

E
Add a denied topic to prevent the chatbot from discussing SQL queries.

Incorrect. Guardrails provide safeguards for GenAI applications. Guardrails support denied topics. Denied topics check that the prompt and completion do not engage in a particular topic. For SQL queries, this approach would prevent the chatbot from generating any SQL queries, including those that are benign. Additionally, this approach would prevent the users from exploring logs.

Learn more about denied topics in Guardrails.

Learn more about prompt attack filters in Guardrails.
