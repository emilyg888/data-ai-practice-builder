Question
A GenAI developer is designing a customer-facing application for a company. The GenAI developer uses an FM that is deployed on Amazon SageMaker AI. The application will deliver automated advisory services to customers. The company requires AI governance controls to ensure compliance with internal policies and external regulations. For compliance, the application must meet the following requirements:

Enforce content restrictions and usage policies during model inference.
Ensure that all model limitations and compliance risks are documented and centrally accessible.
Automate compliance checks on model outputs by using programmatic workflows to flag violations.
Which combination of steps will meet these requirements? (Select TWO.)

Correct answer: A + C

A
Use Amazon Bedrock Guardrails with customized denied topics and blocked keywords based on usage policies. Create an Amazon EventBridge rule to invoke an AWS Lambda function for post-inference policy validation.

Correct. You can use guardrails to define denied topics and blocked keywords to enforce content during model inference. You can use Guardrails for models that you deploy on SageMaker AI. This step reduces the risk of policy violations in AI-generated responses. To validate model outputs after inference, you can configure an application workflow or an EventBridge rule to trigger the function based on inference-related events. This step provides output filtering and enforcement during inference. After inference, this step provides automated compliance workflows programmatically.

Learn more about how to integrate EventBridge with Amazon Bedrock.

B
Integrate SageMaker Clarify with SageMaker Model Monitor to gather metrics across inference endpoints. Export the reports to Amazon S3 for policy compliance audits and governance insights.

Incorrect. You can use Clarify and Model Monitor for bias detection, explainability, and drift analysis. However, these tools focus primarily on model training and inference monitoring. These tools do not enforce policy compliance or document model limitations. Exporting to Amazon S3 is helpful for audits. However, this approach does not provide the automated post-inference validation workflows that you need.

Learn more about Clarify.

Learn more about Model Monitor.

C
Create model cards by using SageMaker Model Registry. Use Amazon EventBridge to trigger compliance workflows that invoke AWS Lambda functions to validate policies at runtime.

Correct. You can use SageMaker Model Cards to provide structured documentation of FM metadata. The metadata can include limitations, training context, and intended usage. You can use EventBridge to capture model registration events and invoke Lambda to enforce compliance policies. This step meets the requirement to centrally document compliance risks and model limitations.

Learn more about Model Cards.

Learn more about events that SageMaker AI sends to EventBridge.

D
Apply IAM policy conditions and AWS CloudTrail Insights on SageMaker AI model invocations. Detect runtime violations through log analysis pipelines.

Incorrect. IAM and CloudTrail are effective for access control and visibility into account activity. However, IAM policy conditions and CloudTrail do not provide content-level filtering or model output validation workflows. IAM policies cannot inspect or filter FM responses. CloudTrail logs are useful for auditing. However, CloudTrail logs cannot automate compliance enforcement or document model limitations.

Learn more about IAM policy conditions.

Learn more about CloudTrail Insights.

E
Use AWS Glue Data Catalog to tag model training datasets with compliance metadata tags, including training provenance and policy classification for downstream documentation.

Incorrect. Data Catalog is a metadata repository that you can use to organize and discover datasets. Data Catalog is not a metadata repository for models. Tagging helps with dataset-level lineage and classification. However, tagging does not directly support policy enforcement, content filtering, or compliance validation workflows.

Learn more about Data Catalog.
