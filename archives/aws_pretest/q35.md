Question
A GenAI developer builds an application by using Amazon Bedrock. The application summarizes customer feedback from multiple media platforms. Currently, the GenAI developer stores all prompt inputs and generated summaries in Amazon S3 for auditing and analytics.

Because of new copyright and compliance policies, the GenAI developer must implement the following governance mechanisms:

Maintain an auditable trail for prompt data sources.
Log FM usage for auditing purposes.
Automatically track prompt lineage and model I/O metadata.
Which solution will meet these requirements?

Correct answer: D

A
Store all prompts and summaries in Amazon DynamoDB with metadata fields for model identifiers and timestamps. Enable DynamoDB Streams to send lineage events to Amazon EventBridge for auditing.

Incorrect. DynamoDB can store metadata including model identifiers and timestamps. DynamoDB Streams can push change events to EventBridge. This solution provides a custom audit pipeline. However, you must build lineage tracking manually. Therefore, this solution does not meet the requirement for automatic governance of prompt lineage. This solution does not provide integrated logging of Amazon Bedrock usage.

B
Create AWS Config rules to monitor Amazon S3 buckets that contain prompts and summaries. Create conformance packs to enforce encryption and retention policies. Export rule evaluations to Amazon Athena for auditing.

Incorrect. AWS Config conformance packs are collections of AWS Config rules and remediation actions. Conformance packs help enforce compliance policies including encryption and retention. Conformance packs are useful for resource governance. However, conformance packs operate at the infrastructure level. Conformance packs do not automatically track prompt lineage, record Amazon Bedrock model usage, or provide I/O metadata.

Learn more about conformance packs.

C
Enable Amazon CloudWatch Logs for Amazon Bedrock model invocations. Set up custom Amazon S3 object tags to capture metadata for each stored prompt and summary. Manage lineage information by using tag policies.

Incorrect. You can use CloudWatch Logs to capture operational metrics and logs that relate to Amazon Bedrock activity. S3 object tags can store metadata values of prompts and summaries. However, this solution relies on manual tagging policies and log management. This solution does not provide consistent or automated governance for prompt lineage or comprehensive auditing of model usage.

Learn more about how to monitor model invocations by using CloudWatch Logs.

Learn more about S3 object tags.

D
Set up Amazon S3 server access logging for all prompt and summary objects. Enable AWS CloudTrail to record Amazon Bedrock API calls. Configure Amazon Bedrock Prompt Management to track template versions and lineage.

Correct. S3 server access logging provides detailed records of requests that are made to S3 buckets. S3 server access logging provides an auditable trail for prompt data sources. CloudTrail captures Amazon Bedrock API activity including model invocations for usage auditing. Prompt Management supports reusable templates, versioning, and lineage tracking for prompts. Therefore, you can use this solution to catalog and review I/O metadata.
