Question
A GenAI developer must create dynamic content filtering for a customer service chat-based AI assistant. Multiple departments in a company use the assistant. The assistant is deployed on an Amazon Nova Pro model. AWS Lambda functions handle the chat logic. The company has the following requirements:

Stricter content policies must be enforced during business hours.
Each department must have department-specific filtering rules.
Amazon Bedrock Guardrails must be used for content filtering.
Which solution will meet these requirements with the LEAST operational overhead?

Correct answer: D

A
Create a single guardrail with maximum restrictions. Create an AWS Step Functions workflow that orchestrates several Lambda functions to post-process responses based on business hours and department. Store filtering rules in AWS Systems Manager Parameter Store.

Incorrect. Guardrails can provide content filtering at the model invocation level. Guardrails has built-in capabilities to manage different filtering contexts. You can create a single guardrail with maximum restrictions. You can use Step Functions with Lambda for post-processing. However, this solution requires additional operational overhead. This solution wastes tokens on responses that would later be filtered out. You must maintain multiple serverless components. A more suitable solution would be to use the built-in features of Guardrails. Filtering at the post-processing stage undermines the fundamental function and granular control of guardrails.
