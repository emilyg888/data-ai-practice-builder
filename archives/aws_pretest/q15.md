Question
A GenAI developer deployed an AI assistant by using an FM in Amazon Bedrock. Users report that when asking similar questions, sometimes the responses are inconsistent. The GenAI developer needs to quantitatively assess the model's sensitivity to slight variations in input questions by using a prompt dataset provided by users.

Which solution will quantitatively evaluate the model's responses across similar input variations?

Correct answer: C

A
Use an Anthropic Claude model in Amazon Bedrock with a temperature setting of 0. Create an AWS Lambda function that calculates Levenshtein distances between responses for similar prompts.

Incorrect. Setting the temperature parameter to 0 can reduce randomness in the token generation process. However, Levenshtein distance is primarily designed to measure string edit distances, not semantic consistency. This solution focuses on surface-level text differences. Therefore, this solution could miss important semantic variations in the model's responses to similar prompts.

Learn more about model parameters in Amazon Bedrock.

B
Deploy an evaluation pipeline using Amazon Bedrock Knowledge Bases and Amazon Titan Embeddings. Calculate semantic similarity scores between responses for similar prompts. Analyze the distribution of embedding distances to quantify consistency.

Incorrect. Embedding-based similarity analysis can measure semantic relationships. Knowledge bases are designed for information retrieval and augmentation, not model evaluation. This solution can provide some insights into response similarities. However, this solution does not provide the comprehensive evaluation framework that you need for a systematic assessment of model consistency.

Learn more about Knowledge Bases.

C
Create a model evaluation job in Amazon Bedrock using the user-provided prompt dataset. Configure evaluation metrics for response consistency analysis. Measure the statistical variance in model outputs across similar input variations.

Correct. Model evaluation jobs in Amazon Bedrock support custom prompt datasets. Model evaluation jobs can produce computed scores and metrics that help you assess the effectiveness of a model and knowledge base. The robustness metric specifically assesses the sensitivity of generated responses based on small variations in the input questions.

Learn more about Amazon Bedrock model evaluation jobs.

D
Set up an Amazon Bedrock agent with systematic testing workflows. Use the agent's orchestration capabilities to process similar prompts in parallel. Analyze semantic coherence through custom evaluation metrics.

Incorrect. Agents are designed to orchestrate task execution and workflow automation. Agents can process multiple prompts. However, agents do not provide the specialized metrics and analysis capabilities that you need for a quantitative assessment of model response consistency.

Learn more about Agents.
