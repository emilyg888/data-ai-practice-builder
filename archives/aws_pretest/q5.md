Question
A healthcare company is using Amazon Bedrock to run a customer service AI assistant. A GenAI developer must use Amazon Bedrock Guardrails to ensure compliance with the following guidelines:

The assistant must comply with healthcare regulations regarding patient privacy.
The assistant should not expose personally identifiable information (PII).
The assistant must avoid discussing unauthorized medical topics.
The assistant should not provide incorrect medical information.
Which combination of configurations will meet these requirements? (Select TWO.)

Correct answer: C + D

A
Configure content filters with high strength for the misconduct category. Create word filters to block unauthorized medical topics.

Incorrect. Guardrails provide content filters with configurable strengths. You can use word filters to block specific keywords or phrases. However, misconduct filters and generic word filters do not provide sufficient compliance for healthcare use cases. This configuration cannot redact PII or restrict specific medical topics.

Learn more about harmful content filters.

B
Configure prompt attack filters to prevent users from bypassing safety mechanisms. Create word filters to detect and block PII.

Incorrect. Guardrails support prompt attack filters that can detect malicious input. For example, attempting to override instructions is malicious input. Guardrails provide word filters to block keywords. This configuration is useful for general safety. However, word filters cannot reliably protect PII.

Learn more about contextual grounding checks.

C
Create sensitive information filters to detect and redact PII in user inputs and model responses. Set up denied topics for unauthorized medical topics.

Correct. You can use sensitive information filters in Guardrails to detect and redact PII. You can use denied topics to block model engagement on specific subjects. This configuration complies with healthcare regulations by protecting PII. This configuration prevents the discussion of unauthorized medical topics.

Learn more about sensitive information filters.

D
Enable automated reasoning checks that validate that model responses adhere to healthcare regulations. Implement contextual grounding to prevent hallucinations.

Correct. You can use automated guardrail checks and contextual grounding checks in Guardrails to ensure that responses are accurate and not hallucinated. These checks verify outputs against retrieval sources. Automated reasoning checks are useful when you need to demonstrate the factual basis for an LLM's response in regulated industries such as healthcare. This configuration helps reduce the risk of incorrect medical information. This configuration helps ensure compliance with factual accuracy requirements.

Learn more about automated reasoning checks.

E
Create reusable templates in Amazon Bedrock Prompt Management. Configure the templates with strict system instructions for healthcare scenarios. Configure denied topics to block unauthorized medical topics.

Incorrect. Prompt Management supports reusable templates and system instructions. However, this configuration does not enforce runtime PII detection or prevent hallucination. This configuration does not meet the compliance and privacy requirements.

Learn more about Prompt Management.
