Question
A large financial services company needs to implement a document processing solution by using generative AI (GenAI). The solution must process mortgage applications that contain sensitive customer information. Each application takes 5–15 minutes to process completely. Each application requires multiple FM calls for information extraction, analysis, and summarization. The solution must handle up to 1,000 concurrent requests during peak hours. The solution must provide audit trails for all AI model interactions. After processing, the results should be available for users to retrieve.

Which solution will meet these requirements with the LEAST operational overhead?

Correct answer: B

A
Create an Amazon API Gateway API with AWS Lambda functions that make synchronous calls to Amazon Bedrock for document processing. Store results in Amazon DynamoDB after processing.

Incorrect. API Gateway is a fully managed service that you can use to create and manage APIs. API Gateway has a 29-second timeout quota. Lambda functions have a 15-minute timeout quota. These quotas make synchronous processing unsuitable for documents that take 5–15 minutes to process. This solution would fail for longer-running processes. This solution does not efficiently handle concurrent requests during peak hours.

B
Use Amazon S3 to store document uploads. Set up S3 Event Notifications to invoke an AWS Lambda function. Configure the Lambda function to invoke an AWS Step Functions standard workflow that orchestrates Amazon Bedrock model calls. Store processing status and results in Amazon DynamoDB for retrieval.

Correct. Amazon S3 provides scalable, secure object storage for documents. S3 Event Notifications can invoke an AWS Lambda function. Step Functions standard workflows can run for up to 1 year and maintain detailed execution histories for auditing. Step Functions can handle the orchestration of multiple Amazon Bedrock model calls. DynamoDB provides fast, consistent access to processing status and results. This solution uses fully managed services that provide concurrent processing, audit trails, and result retrieval. Therefore, this solution requires the least operational overhead.

C
Create an Amazon Kinesis data stream to receive documents. Use Kinesis consumer AWS Lambda functions to process documents in parallel through Amazon Bedrock APIs. Store results in Amazon OpenSearch Service for retrieval.

Incorrect. Amazon Kinesis Data Streams provides real-time streaming data ingestion. Data streams can scale to handle concurrent requests. For this solution, you must manage stream sharding, monitor Lambda consumer functions, and maintain an OpenSearch Service cluster. You must manage processing state and audit trails. Therefore, this solution requires additional operational overhead.

D
Configure Amazon API Gateway with WebSocket APIs to maintain connections while Amazon Bedrock processes documents. Create an AWS Lambda function to send status updates to connected clients.

Incorrect. API Gateway WebSocket APIs provide two-way communication between clients and servers. However, maintaining connections for 5–15 minutes for each document is resource-intensive. WebSocket connections can remain open for up to 2 hours. However, managing thousands of concurrent long-lived connections increases operational overhead. You must handle connection state, implement reconnection logic, and manage client notifications.
