Question
A research company is using a customizable FM on Amazon Bedrock to develop an internal generative AI (GenAI) powered search interface. During testing, a GenAI developer discovers that the model's performance is suboptimal for a specific niche topic. The company has 3 TB of unlabeled proprietary research papers, technical documentation, and historical reports that cover the niche topic.

The company wants the model to develop a deeper understanding of the niche topic's domain terminology, concepts, and relationships. The GenAI developer must improve the model's accuracy for the niche topic by using the proprietary data.

Which solution will meet these requirements?

Correct answer: B

A
Use the proprietary data to fine-tune the model in Amazon Bedrock.

Incorrect. Fine-tuning is a technique that can improve model performance. However, fine-tuning requires training data in the form of labeled examples. The model learns to associate which types of outputs to generate for certain types of inputs. In the scenario, the company wants the model to develop a deeper understanding of a topic, not to answer specific questions.

Learn more about model customization.

B
Use the proprietary data to perform continued pre-training of the model in Amazon Bedrock.

Correct. With continued pre-training, a model can learn from large amounts of unlabeled domain-specific data. This solution continues general language model training on new content. The model can develop a deeper understanding of the domain's terminology, concepts, and relationships from the 3 TB of proprietary data.

Learn more about model customization.

C
Use the proprietary data as an input for knowledge distillation to transfer insights from the current model to a new model.

Incorrect. Knowledge distillation is a technique that creates a smaller, more efficient model by transferring knowledge from a larger model. Knowledge distillation can transfer knowledge. However, knowledge distillation is not an effective way to incorporate large amounts of new specialized data. This solution focuses on model compression and efficiency. This solution does not improve domain understanding.

Learn more about knowledge distillation.

D
Use an LLM to summarize the proprietary data. Incorporate the summary as a system prompt for the current model.

Incorrect. System prompts are instructions or context that can guide a model's behavior during inference. System prompts can provide context to the model. However, this solution is not an effective way to incorporate large amounts of specialized data. Prompts are suitable to guide model behavior, not to extensively expand a model's knowledge base.

Learn more about prompt engineering.
